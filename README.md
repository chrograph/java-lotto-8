# java-lotto-precourse

## 실행 과정 
1. 구매 금액 입력
2. 당첨 번호 입력
   - 번호는 쉼표(,)를 기준으로 구분
3. 보너스 번호 입력
4. 당첨 내역 출력
   - 로또 번호는 오름 차순으로 정렬하여 출력
5. 수익률 출력

## 기능 목록
- [X] [입력] 
    - [X] 구매 금액
      - 숫자가 아닐 시, 에러 문구 출력 
      - 빈 문자열 입력 시, 에러 문구 출력
    - [X] 당첨 번호
      - 구분자가 쉼표(,)가 아닐 시, 에러 문구 출력
      - 숫자가 아닐 시, 에러 문구 출력
      - 당첨 번호 중복 시, 에러 문구 출력
      - 6자리 초과 시, 에러 문구 출력
    - [X] 보너스 번호 
      - 당첨 번호랑 중복 시, 에러 문구 출력 
- [ ] [출력]
  - [X] 로또 수량 출력
  - [X] 로또 번호 출력
    - 각 로또 번호는 오름 차순으로 정렬
  - [X] 당첨 내역 출력
  - [X] 수익률 출력
    - 소숫점 둘째 자리에서 반올림
- [ ] [기능]
  - [X] 1에서 45 사이의 중복되지 않은 정수 6개 반환
    - 로또 발행 수 만큼 반복
  - [X] 당첨 통계 계산
  - [X] 수익률 계산

## 예외 출력
- 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.
```
[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
```

## 프로그래밍 요구 사항
- 자바 코드 컨벤션을 지키면서 프로그래밍한다
- indent depth 2까지만 허용
- 3항 연산자 사용X
- 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현
- else 예약어 사용X
- Java Enum을 적용하여 프로그램을 구현
- 구현한 기능에 대한 단위 테스트를 작성
